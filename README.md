# ドライブ移行 (drive-bridge)

スマホのダウンロードフォルダに新しく来たファイルを、Googleドライブへ自動で送る Android アプリ。

## 仕様（固定・これだけ）

- ダウンロードフォルダを見張る
- 新しく来た **rar・zip ファイルだけ**を自動でアップロードする
- アップロードのとき、ファイル名の文字化け（化けた日本語名）を正しい日本語に直して入れる
- 大きいファイル（200MB以上）でも送れるよう、小さい塊に分けて送る再開できるアップロード（レジューマブル）を使う
- それ以外の機能は入れない

## 進め方

- ミルク（Muse）が GitHub にコードを書く → Codemagic が自動でビルド → ユーザーが実機に入れて確認し、直しを一つずつ伝える
- ビルドは `codemagic.yaml` の形（リポジトリに android フォルダは入れず、ビルド時に生成する）

## 段取り

1. 土台（いまここ）：画面の骨組み・日本語設定・ビルド設定
2. Google アカウントへのサインイン設定（初回だけ・案内しながら）
3. フォルダの見張りとアップロード本体
